# Homebrew tap for Fjord

[Fjord](https://github.com/jhtjernsmo/fjord) is a local-first, keyboard-first project manager.

```sh
brew install --cask jhtjernsmo/fjord/fjord   # the app (macOS, signed and notarized)
brew install jhtjernsmo/fjord/fjord-cli      # the `fjord` command-line tool and MCP server
```

The app updates itself; `brew upgrade` works too. This tap is updated with every Fjord release.
